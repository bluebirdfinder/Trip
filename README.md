# 首爾慢活．四天三夜

給表哥和我的首爾旅遊行程網站，2026/9/19（六）～9/23（三），吃吃喝喝為主、景點隨緣的鬆散行程，附釜山交通懶人包與行前準備清單。

## 內容

- `index.html` — 全站內容（總覽、Day1～Day5 行程、美食清單、釜山 Q&A、行前準備）
- `css/style.css` — 視覺樣式（韓國宮殿丹青紅＋秋日銀杏黃的配色系統，支援手機／深色模式）
- `js/script.js` — 目錄捲動高亮、手機選單、倒數天數、滾動淡入動畫

## 本機預覽

直接用瀏覽器開啟 `index.html`，或在專案資料夾執行：

```bash
python3 -m http.server 8000
```

再開 `http://localhost:8000`。

## 部署到 GitHub Pages

Repo 設定 → Pages → Source 選擇這個分支的根目錄即可發布。

## 圖片說明

因為建置環境暫時沒有對外網路可以抓取／驗證圖床連結，這版沒有嵌入外部照片，改用手繪 SVG 插畫呈現主視覺，並在每個景點／餐廳都附上「📍 Google 地圖」連結，可以直接看到最新真實照片與評價。之後若要換成實拍照片，把對應的 `<svg>`／icon 換成 `<img>` 即可。
